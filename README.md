# Innebandyresultat

En enkel, kostnadsfri statisk webbplats för att samla ett barns innebandymatcher.

## Ändra matcher
Öppna `app.js` och lägg till poster i `matches`:

{date:"2026-10-04", opponent:"Motståndarlag", score:"5–3", type:"Seriespel", event:"P13 Västra"}

För cup:
{date:"2026-10-05", opponent:"Motståndarlag", score:"4–2", type:"Cup", event:"Gothia Innebandy Cup"}

## Publicering
Mappen kan publiceras gratis på GitHub Pages, Cloudflare Pages, Netlify eller Vercel.

Nästa steg kan vara att bygga:
- administratörsvy för att lägga till matcher
- riktig databas
- klickbar cup-/motståndarhistorik
- detaljerad matchvy
- statistik per säsong
