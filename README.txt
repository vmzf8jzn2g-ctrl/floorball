INNEBANDYRESULTAT 2026

Detta är en statisk Vercel-klar webbplats. Ladda upp index.html till ett Vercel-projekt
eller koppla ett Git-repo. Ingen build eller databas behövs.

För att lägga till matcher: öppna index.html och redigera listan `const matches = [...]`.
Varje match har competition, type, stage, home, away, homeGoals, awayGoals, date, time
och venue.

Serier kan läggas till genom att sätta type till "seriespel" och använda exempelvis
competition: "Seriespel 2026/27".
